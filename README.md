# *celaria-formats*

[![npm package version badge.](https://img.shields.io/npm/v/celaria-formats.svg)](https://npmjs.com/package/celaria-formats)
[![Open issues badge](https://img.shields.io/gitea/issues/open/BunnyNabbit/celaria-formats?gitea_url=https%3A%2F%2Fcodeberg.org)](https://codeberg.org/BunnyNabbit/celaria-formats/issues)
[![Coverage status badge.](https://coveralls.io/repos/github/BunnyNabbit/celaria-formats/badge.svg?branch=main)](https://coveralls.io/github/BunnyNabbit/celaria-formats?branch=main)

Library for parsing and writing various file formats for the first-person parkour game [Celaria](https://www.celaria.com/).

## Supported formats

- *read/write* `.ecmap`: [Editable Celaria map](https://bunnynabbit.github.io/celaria-formats/classes/CelariaMap.html).
- *read/write* `.cmap`: [Celaria map](https://bunnynabbit.github.io/celaria-formats/classes/EditableCelariaMap.html).
